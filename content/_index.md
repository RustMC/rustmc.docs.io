RustMC is an open-source Minecraft Java Edition 26.3 server written in Rust. It
is built from published protocol documentation, the official game data
reports and measurements against real vanilla worlds, not from other servers'
code. Correctness comes first: every compatibility claim carries its
evidence, and speed is measured, not promised.
